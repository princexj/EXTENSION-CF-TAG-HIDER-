## 1. Store Listing Details

### **Extension Name**
```text
Codeforces Problem Tag Hider
```

### **Summary** (Max 132 chars)
```text
Hides spoiler problem tags (e.g. brute force, dp, greedy) on Codeforces with click-to-reveal, hover peek, and rating preservation.
```

### **Detailed Description**
```text
Enhance your competitive programming practice on Codeforces without algorithm spoilers!

When practicing on Codeforces, seeing problem tags like "dp", "brute force", "binary search", or "graphs" ruins the problem-solving process by giving away the core technique before you even begin thinking.

Codeforces Problem Tag Hider automatically conceals topic tags on problem pages, contest pages, and problemset listings, allowing you to train with authentic contest focus.

✨ KEY FEATURES:
• Zero-Flash Tag Hiding: Declarative CSS hides spoiler tags instantly at document start — no momentary spoiler flash while the page loads.
• Keep Difficulty Rating Visible: Keep problem ratings (like *1400, *1700, *2100) visible while hiding the algorithm tags, so you always know the challenge level.
• 3 Flexible Display Modes:
   1. Click to Reveal (Spoiler): Replaces tags with a clean "Reveal Problem Tags" button.
   2. Hover to Reveal: Smoothly blurs tags until you hover over them.
   3. Always Hidden: Completely removes the tags container for ultimate stealth.
• In-Page Header Toggle: Injects an intuitive [👁️ Show Tags] / [🙈 Hide Tags] button directly into the problem tags sidebar header.
• Problemset Table Protection: Blurs tags in the /problemset table rows so browsing never spoils algorithms.
• Lightweight & 100% Private: Zero external tracking, zero analytics, zero data transmission. Runs entirely inside your browser.
• Dark & Light Theme Support: Blends seamlessly with both Codeforces default and community dark modes.

COMPATIBILITY:
Works smoothly on Brave, Google Chrome, Microsoft Edge, and all Chromium browsers across all Codeforces problem pages, gym problems, mashups, and contest archives.

OPEN SOURCE:
Codeforces Problem Tag Hider is open-source under the MIT License:
https://github.com/princexj/EXTENSION-CF-TAG-HIDER-
```
